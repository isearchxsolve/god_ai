# CANVA DESIGN GUIDE
## Specs
- **Size:** 1200 × 1200 px (LinkedIn square)
- **Background:** White (#FFFFFF)
- **Font:** Inter Bold or Montserrat Bold
- **Main Text:** Black (#000000)
- **Accent:** Orange (#FF6B35) — only on "Comment REEL"

## Text Layout (top to bottom)
1. "I create cinematic reels" — 72pt, bold
2. "for founders, creators," — 72pt, bold  
3. "and musicians" — 72pt, bold
4. [spacer]
5. "1 reel: ₹1,500" — 60pt, bold
6. "3 reels: ₹4,000" — 60pt, bold
7. [spacer]
8. "Comment REEL" — 64pt, bold, ORANGE (#FF6B35), underlined

## Steps in Canva Free
1. canva.com → Create Design → Custom Size → 1200×1200
2. Background → White
3. Text → Add Heading → paste each line → format
4. Select "Comment REEL" → Text Color → #FF6B35 → Underline
5. Center all horizontally
6. Share → Download → PNG → Save as `reel-offer.png`
