## HOW TO SET UP STRIPE INSTANT PAYOUT (Step by Step)

### Step 1: Create Stripe Account
1. Go to stripe.com
2. Sign up with email
3. Fill business details (name, address, EIN/tax ID)
4. Link bank account and debit card

### Step 2: Enable Instant Payouts
1. In Stripe dashboard, go to Settings → Payouts
2. Connect a debit card (not just bank account)
3. Enable "Instant Payouts" option
4. Verify card (small test deposit)

### Step 3: Create Payment Link
1. Go to Payment Links in dashboard
2. Create new link
3. Add product name, price ($497 for bundle)
4. Add description (copy from your Gumroad description)
5. Generate link: `pay.stripe.com/...`

### Step 4: Add to Your Website
1. Build simple page on Carrd.co (templates available)
2. Add "Buy Now" button linking to Stripe payment link
3. Or embed Stripe checkout directly

### Step 5: Get Paid Instantly
1. Customer pays → Money in Stripe balance
2. Go to dashboard → Click "Instant Payout"
3. Money on your debit card in **minutes**
4. Costs extra 1.5% but you have cash NOW
