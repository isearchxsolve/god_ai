# Daily Earning Reminder — 10 AM Start

**Rule:** This runs every weekday. No exceptions. If you miss 10 AM, start immediately when you see this.

---

| Action | Tool | Done? |
|--------|------|-------|
| Open LinkedIn desktop | Chrome → linkedin.com | ☐ |
| Open payment link dashboard | Gumroad / Payhip dashboard | ☐ |
| Open today's post draft | Google Docs (bookmark) | ☐ |

| Set 50-min timer | Phone timer | ☐ |

**Mental cue:** "One offer. One post. Fifteen DMs. One link. One visual."

## 10:10–10:30 — POST (20 min)

### Pick ONE offer for today
- **Service:** "I build cinematic AI reels — ₹1,500/reel, ₹4,000/3-pack"
- **Product:** "Free GPU Film Lab — ₹499" (PDF)
- **Bundle:** "AI Creator Starter Kit — ₹1,999" (3 PDFs)

### Write the post (copy-paste template)
```
[HOOK — 1 line, outcome-focused]
I help founders/creators turn ideas into cinematic AI reels using free GPUs.
Same character. Same visual identity. Every shot.

[PROOF — 1 concrete line]
Last week: delivered 3 reels for a musician in 48 hrs on Kaggle T4s. Cost: ₹0 cloud spend.

[OFFER — 1 clear line]
Taking 2 reel clients this week at ₹1,500 each. Or grab the PDF guide (₹499) and build yourself.

[CTA — 1 line]
Comment "REEL" for service details. Comment "PDF" for the guide link.
```

### Post it
- Paste into LinkedIn
- Add 3 hashtags max: `#AIvideo` `#cinematicAI` `#founderbrand`
- **No link in post** — link goes in first comment or DM

### First comment (your own)
```
Link here: [Gumroad/Payhip product URL] or DM me "REEL" for service details.
```
